# 经验：并行后台任务的落盘竞态

- **skill**: research-autopilot / 所有并发执行场景
- **failure_mode**: 产物落盘位置错误（E5 类执行缺陷）
- **为什么**: shell 的 `&` 后台任务从解析点 fork，不继承运行时 `cd`——`cd dir && A && B & C &` 中 C 在原 cwd 执行，相对路径 `-o C.json` 落到错误目录（2026-10-19 实测：5 个检索结果文件散落项目根目录，靠全盘 find 才归位）。
- **如何应用**: 并行后台任务的写盘一律显式绝对路径；批量任务完成后立即 `ls` 验证落盘位置与数量；产物校验（如 Gate Check 的文件存在性断言）天然兜底此类错误。
