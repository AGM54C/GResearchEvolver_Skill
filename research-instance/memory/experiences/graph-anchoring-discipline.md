# 经验：综述生成必须走图锚定（G 路径），自由写作产生系统性滑变

- **skill**: survey-architect（及一切产出论断型文本的 skill）
- **failure_mode**: 无依据确认 + 过度泛化（自由写作时凭印象发挥，四类滑变）
- **为什么**: graph-ab-1 对照实验实测（2026-10-19，同主题同材料）：无图直写基线 17 论断中 4 条 broken（严格可回接率仅 64.7%），滑变形态全部命中 LLM 综述典型错误——① 多源泛化（单源「HalluLens 指出定义混同」写成「多篇综述都指出」）；② 来源混淆（笔记读者评论「有意性维度缺失」冒充文献结论并泛化为「普遍缺失」）；③ 弱证据强化（推论态「可在高风险场景支撑框架」写成「已得到应用」）；④ 编造结论（材料无 PSRD 有效性证据且笔记明确质疑，仍写「有效降低幻觉率」）。而图锚定路径 18/18 全部可回接（100%），refute/condition 边强制并陈 + evidence.scope 随陈述保留使四类滑变在结构上不可发生。
- **如何应用**: graph.json 存在时综述/IDEA 生成**必须**走 G 路径（HARNESS §4.6）：L0 粗筛 → 图定位 → 节点锚定生成，**无锚论断不得写**；推论/潜力态论断保留模态（可/已分清）；读者评论与文献论断严格分离（笔记「我识别」类内容不得直接入正文）；图缺席降级 flat 检索 + EVIDENCE_MISSING，不凭印象补写。
