# 经验：多源文献检索的三个工程坑（arXiv/S2/OA/Crossref）

- **skill**: literature-miner
- **failure_mode**: 条件错误合并（去重键不归一）+ 限速处理不当（硬重试）
- **为什么**: ① arXiv API 返回的 ID 带版本后缀（`2602.19643v1`）而 OpenAlex 的 DOI 提取不带（`2602.19643`），键不归一使同一文献以两个身份入库（2026-10-19 实测 3 条重复）；② S2 未认证限速极严，连续请求必 429，原样重试无效；③ OA 无 key 时与全网共享 IP 每日 $0.10 额度，高频检索会被限制。
- **如何应用**: 多源合并前先做 ID 规范化（去版本号/去 URL 前缀/统一大小写），并维护 arXiv-ID 与 DOI 双键索引；S2 串行+间隔，失败 2 次即降级缺席输出 EVIDENCE_MISSING，绝不编造；OA 高频场景申请 API key 或降频。
- **增量（2026-10-19 干预重放验证）**: ① ID 归一化的有效性已由重放独立验证（31 条→27 unique，跨源键不归一 + 同源多查询重复两类机制一并覆盖）；② S2 未认证限速下 **30s 间隔不够**（2 轮 4 请求全 429）——降级阈值应更激进：1 次间隔重试仍 429 即降级，勿恋战。
