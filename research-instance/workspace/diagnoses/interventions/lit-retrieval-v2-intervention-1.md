- **预期观察**：重复条目 3→0，且总条目数不丢失（去重只合并身份，不删数据）

## INT-2（DE-2，I1a 加具体化）— 并行落盘显式绝对路径

- **预期观察**：散落文件（对照组重现）→ 实验组 0 散落

## INT-3（N-1，I3 配置级）— S2 限速策略（串行+间隔）

- **操作**：真实重放 S2 API 请求：单次带 ≥30s 间隔的串行请求（对照 v1 的连续+原样重试）
- **验证条件**：若返回 200 → 干预有效（串行+间隔可避开限速窗口）；若仍 429 → 按协议**降级缺席输出 EVIDENCE_MISSING，不再原样重试**（干预的成功标准 = 重试策略正确，而非 S2 必须成功）
- **预期观察**：不再出现「429 后原样重试仍 429」的无效重试序列
