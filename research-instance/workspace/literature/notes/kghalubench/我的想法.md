# KGHaluBench: A Knowledge Graph-Based Hallucination Benchmark

[arXiv:2602.19643](https://arxiv.org/abs/2602.19643) · abstract_only · 2026

**一句话：**用知识图谱动态出题 + 双层验证（概念层/正确性层）评 LLM 知识的广度与深度，处理流行度偏差。

**怎么做：**KG 动态构建多维问题 → 统计估计难度 → 自动化管线检测弃权并分型幻觉。

**局限：**（作者自述）现有基准静态狭窄。（我识别）KG 本身的覆盖偏差会传导到题目分布；「广度/深度」的判定依赖 KG 质量，KG 未覆盖≠LLM 错。

**我的想法：**与本研究方向最直接相关：KGHaluBench 的「概念层验证 + 正确性层验证」双层结构，与我们的「GNN 子图召回（仅候选）+ 规则层证据资格裁决」边界划分同构——都拒绝图连通即正确的越界。可作为一个对照点：他们的双层用在评测出题，我们的两层用在证据裁决。另其「难度统计估计处理流行度偏差」可迁移到我们论断图的抽样复核（高频节点不应主导抽查）。

原文定位：abstract s1-s5；§3.1 Question Generation；§3.2 Response Verification。

**全文发现（v2 增补）**：① 出题管线五步全貌：实体检索→属性检索→流行度→问题生成→难度统计估计（C-kghalu-5）；② 验证双层结构落位于 §3.2.1 Entity-Level Filter 与 §3.2.2 Fact-Level Check（C-kghalu-6）——与 HalluLens 的 LLM judge 高准确率实测（96.67%）构成跨文献工程可行性互证（E-16 弱支持边）；③ 其「幻觉」界定为知识广度/深度（truthfulness），与 HalluLens「幻觉须与 factuality 解耦」存在定义域分歧——E-10 refute 边的依据，但 KGHaluBench 正文是否点名 HalluLens 未核验（未决项）。
