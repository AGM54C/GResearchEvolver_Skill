# Probabilistic distances-based hallucination detection in LLMs with RAG

[arXiv:2506.09886](https://arxiv.org/abs/2506.09886) · abstract_only · 2025

**一句话：**用 prompt 与回复 token 嵌入分布的距离做 RAG 场景幻觉检测，考察隐状态几何结构提取事实性信号。

**怎么做：**分布距离估计 + 长序列友好的几何结构分析。

**局限：**（作者自述）多数已有方法不为 RAG 设计。（我识别）嵌入距离是相关性代理而非因果证据——分布近≠事实对；摘要未报告假阳性率与跨域泛化。

**我的想法：**「隐状态几何结构承载事实性信号」是我们 LLM 内部诊断（level=agent+llm）的外部对照方法：探针读出（内部）与嵌入距离（外部几何）若不一致，本身就是诊断信号。可作为 Agent+LLM 联合诊断 IDEA 的候选基线之一——注意是「基线/对照」而非「待验证假设」，避免与 SEAL 红线冲突。
