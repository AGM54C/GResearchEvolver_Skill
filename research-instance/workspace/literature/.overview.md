# literature/ — 文献工作区

LLM 幻觉方向文献库 v2（literature-scholar 产出）：检索 → 精读 → 原子论断建图三层结构。

## Quick Navigation

- `index.md`：文献总索引（6 篇 × 笔记/条目/节点范围对照表）——**入口文件**
- `graph.json`：论断图 v2（30 节点 / 16 边 / 6 篇文献），survey/idea/diagnosis 的检索底座
- `entries/`：6 篇原子论断条目（hallulens / psrd / lifecycle-survey / kghalubench / probdist-rag / can-llms-lie）
- `notes/`：6 篇精读笔记目录（每篇一个子目录，含「我的想法」）
- `inbox/`：检索原始层——`papers.json`（三源 57 篇）、`raw/`（API 原始返回，可复核）、`fulltext/`（3 篇全文文本）、`queries.md`/`relevant.json`
- `report.md`：检索轮报告（v2 多源执行记录）

> S2 引用图数据因限速降级缺席（`EVIDENCE_MISSING`，见 inbox/index.md）。
