# 长程科研 Agent：验证报告

## 验证目的与方法

验证复制的 MemTX 确实执行事务和撤回，长程协调在上下文切换、证据修订、并发预算、人工介入和崩溃后仍遵守约束，并确认原有能力没有被删除。离线测试采用明确标注的模型 HTTP fixtures，但实际运行上游代码、监督子进程、数据库、备份和本地 DAG；另用本机已配置模型进行一次受限线上检查。

## 覆盖的关键失败路径

- 上游提交、低支持记忆隔离、不同来源冲突、同来源替换及 typed cascade；跨进程恢复创建时间、逻辑日期、状态和权限元数据。
- 逐项检查动作实际前提，拒绝无关 action_safe 记忆借权、过期记录、缺失／被替代祖先；只读查询不改变受审快照。
- Agent 不能冒充人类来源、取得高权威豁免或操作别人的事务；拒绝覆盖已有 memory_id、未知风险等级与错误日期。
- 科学版本、条件和内容改变会阻断旧绑定；源失效通过上游撤回，显式替代支持路径可保留，相关关系不会误作依赖级联。
- 两次自动上下文交接仍保留真实人工意见和完整归档，工具没有重放；父会话完整历史可分页读取；必保留信息过大时停止。
- 两个会话并发争用同一项目预算只允许一方成功；fork 不重置额度；崩溃后预算与意图一并恢复，重复结算不重复收费。
- 等待真实 DAG 不调用模型；暂停期间不被实验结果强制唤醒；失败转交人类；产物导入前检查配额并按回执版本保留。
- 项目／MemTX／报告的完整备份恢复与 CAS 核验；经验提案绑定实际项目事件中的快照，拒绝伪造快照和改写后条目，仍需原 RSI 评估与人工采用。

最初有一项测试把“同来源等权新值”预期成冲突隔离。检查上游原代码后确认它明确采用替换语义，测试改为不同来源的冲突，并另增加“被替代祖先不能继续授权动作”的用例。没有为让测试通过而修改上游文件。

## 真实模型检查的准确含义

请求模型为 `gpt-6-astra`，通过本机既有配置的 Responses 接口访问。预算上限为 10 次模型请求、24 次工具调用、360 秒受管 worker 时间、20,000 输出预留 token。实际 7 次模型请求、6 次工具执行、约 74.69 秒；提供方报告 71,899 输入和 1,809 输出 token。

它读取项目，实际调用 Holm 校正，写入 results.md，并为 report_stage 绑定真实 calculator 记忆。系统进入 `awaiting_researcher / scientific_review`，待审 report_stage 没有被执行。测试没有替研究者接受，没有伪造专家审查，也没有把 fixture 算成科学发现。

真实模型检查先于最终父归档读取、只读快照和经验来源加固；这些后续变更由最终离线回归覆盖。[source-bindings.json](source-bindings.json)列出版本差异与最终来源哈希，不能把先前线上调用称为最终全部路径的线上实测。

原始模型请求／响应、监督日志、SQLite/CAS 和项目报告保留在工作区 `GResearchEvolver-LongHorizon-Validation-20261021/live-long-model/state/`。分发源码只包含不带凭据的摘要、示例产物和测试。

## 交付与复现

运行 `python -X utf8 -B tests/run_checks.py --report validation.json` 可复查全部离线用例。`tests/live_long_horizon.py --output <新目录>` 会实际消耗已配置模型额度，并按设计停在人工审阅门前。

`build_agent.py` 生成完整本地 Agent ZIP，包含全部 26 个技能、运行器、MemTX、文档与测试；每个文件有 SHA-256，构建器检查 200 MB 上限。最终 ZIP 的精确大小与哈希见旁边 `.manifest.json` / `.sha256`。运行状态、密钥和模型权重不在包内。MemTX 的许可仍为 NOASSERTION；本次没有公开推送或发布包含它的新 Release。

## 不能由本轮得出的结论与待反馈

没有多日压力／故障注入服务等级证明，也没有新增真实 SSH 长程作业的端到端实测。MemTX 的状态检查、哈希和人工接受不证明语义蕴含；复制上游也不代表其论文指标已经复现。没有跨领域科学能力基准、效率收益结论或导师／同学用户研究。
