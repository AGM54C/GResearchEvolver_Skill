# v2.1：实际验证、修复和剩余边界

本轮按用户要求增加真实模型/数据评估、候选权限隔离、语义复核、外部集成与可实施的 HCI pilot。绘图和 PPT 不在范围内。原始 22 篇文献与历史 research-instance 保持不变。

## 改变了什么

- **RSI 执行边界**：可选固定镜像 Docker；候选非 root、零有效 capabilities、无网络、代码/当前输入只读。评分器、完整任务集、数据库和 Ed25519 密钥不挂载。监督器限制资源并清理后代，输出仅允许有界 JSON 常规文件；无可用隔离环境时失败，不降级执行。默认 audit 使用不重叠的新批次，失败也消耗；签名晋升绑定评估上下文，发布端钉住公钥并拒绝重放。
- **语义证据复核**：真实模型接口与严格 JSON schema，逐项检查否定、量词、人群、因果、语气、数字条件，绑定原文哈希和字符偏移。图模式先验证来源完整性，保留反证/拒判，不覆盖人工裁决。模型高自报置信度不能充当校准概率。
- **可执行模型适配**：Responses、Chat、Ollama、现有 Codex API-key 配置；请求/返回模型身份、用量、耗时与失败留痕。真实向量 API、离线 safetensors 编码器、实际隐藏层与可训练线性诊断器均有接口；诊断器校验分区、文献组泄漏、维度和数值。
- **远程执行**：SSH/SFTP 支持显式端口和固定 host key、独立作业目录、取消、超时、30 秒断线租约及 Linux subreaper 后代清理。未收到远程清理回执时明确未确认；停止计算不撤销外部业务作用。
- **人工研究**：[HCI 方案](HCI-STUDY.md)、真实 Wine/SciFact [任务材料](../benchmarks/hci-materials/)、独立评分键、平衡分配、空观测表和按参与者配对的分析脚本。尚未运行用户研究。

## 同模型、同任务、同上限的真实小基准

固定 `gpt-6-astra`、low reasoning；每组每任务 1 次调用、输入最多 24,000 tokens（含提供方开销）、输出最多 2,400 tokens、模型 120 秒、隔离执行 30 秒，不修复重试。服务商返回同名模型；内部模型修订不能独立认证。

真实数据为 sklearn/UCI Iris、Wine、Breast Cancer，覆盖植物、化学、肿瘤数据。各自做组统计和训练/测试分类，共 6 个微任务；oracle 在调用前由 NumPy/sklearn 计算并冻结，生成程序在隔离环境用标准库运行。对照是直接完成任务，处理是加载本项目统计/复现/共享技能指令。该实验**没有比较 Auto-Research-Skills 的完整自主流程**，也不是开放科研发现基准。

| 组 | 六项任务平均得分 | 输入 tokens | 输出 tokens | 模型调用时间合计 |
|---|---:|---:|---:|---:|
| direct | 1.000 | 85,307 | 2,721 | 72.38 秒 |
| evidence_skill | 1.000 | 91,169 | 2,902 | 71.94 秒 |

所有上限均满足，两组均完成。相同预算指同一上限，并非强行让实际消耗相等。以数据集为独立单位、两个任务为组内重复，平均差为 0；三个数据集的 bootstrap 输出 [0,0] 是当前样本满分平局造成的退化区间，不表示总体差异已被精确估计。任务存在天花板效应，不能证明等效或更强；后续需要更困难、预先保留且不用于开发的任务和重复调用。

## 人工标签语义评估与隐藏状态诊断

从官方 SciFact train/dev 选择按文献组隔离的真实标签，先冻结数据、提示、阈值选择规则，再调用模型。每轮 12 条校准、24 条评估，三个类别均衡；这只是生物医学摘要的探索性样本，不代表跨学科总体，也无法排除公开数据进入预训练。

第一轮输出把部分 enum 写成解释文本，结构校验将全部结果拒判。修复完整枚举提示和 JSON schema 后，第二轮使用与第一轮完全分离的文献组；加强矛盾判定规则前的评估记录为 **19/24 正确，4 个错误、1 个拒判**。没有任何预设阈值在校准集达到要求，因此自动采纳覆盖率为 0。随后独立软件验收加强了矛盾/不确定性校验；同一原始响应经最终代码确定性重校验后为 **16/24 正确，3 个错误、5 个拒判**，非拒判部分正确率 16/19。原阈值保持不变，自动采纳覆盖率仍为 0。四条预测变化及原始结果均保留，不能将重校验计为新的外部样本。

实际载入缓存的 `sentence-transformers/all-MiniLM-L6-v2` 固定快照，使用最后两层 masked mean、逐层 L2 后拼接为 768 维，记录所有模型文件哈希和截断。60 条训练、12 条校准、24 条评估均按文献组隔离。训练的 multinomial logistic 诊断器仅 **8/24 正确（33.3%）**，校准不支持自动采纳，覆盖率为 0。为补存逐例预测，用同一数据/编码器重跑，结果未变；不是新增独立实验。这个负结果不支持将此配置用于自动语义裁决。接口保留为实验能力，也不称作 Latent Critic/ReCast 论文复现。

## 如何使用这些结果

默认 trusted-local 仍需信任代码；Docker 隔离信任控制器、宿主内核、daemon 和镜像，不是对内核漏洞的防护证明。新审计批次减少重复适应性使用，不能消除任务设计偏差和语义近重复。专家 RoB/GRADE 判断、测量有效性、因果识别、形式化命题对齐仍应由合适的方法与人员完成；这类责任不能通过删去限制说明来解决。

目前已补充可运行机制和有限实测，没有证明“最强”“零幻觉”或全球首创。HCI 方案可由导师和同学实施，正式结论仍需真实、去标识化观测。不可达的服务器、接口曾遇到的限流和没有提供的私有库保持明确状态，不用 fixtures 冒充在线验证。

验证脚本在 [benchmarks](../benchmarks/)，最终冻结输入、实际模型输出、用量和评分摘要在 [validation-v2.1](validation-v2.1/)。发布整理删除了 50 份重复请求/复核输出、重复编码器运行文件、一次性验收报告和详细调试回执；保留 82 份最终证据。失败事实保留在[开发问题摘要](validation-v2.1/development-history.json)与[独立验收失败案例](validation-v2.1/independent/initial-failures.json)，原明细仍可在历史提交 `9fed233` 查到。语义调用的共同设置另存为 request-template.json；原始模型回答、冻结协议和负结果保留。下载缓存、私钥、临时运行目录与开发快照已删除。
