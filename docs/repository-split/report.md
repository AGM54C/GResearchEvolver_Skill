# Skill 仓库拆分报告

本仓库继续负责 26 个科研技能、注册表、共享科研协议、绘图/PPT 辅助脚本和宿主安装。执行引擎、长程项目与工作台转由 [Agent 仓库](https://github.com/AGM54C/GResearchEvolver_Agent) 维护；Skill 中保留固定版本的兼容快照，因此既有宿主、CLI 和实验无需立即迁移。

`dependencies/runtime.lock.json` 记录来源提交与逐文件哈希；CI 检查快照和真实上游提交一致。直接修改消费副本会报错；更新方法见 [维护边界](../REPOSITORY-SPLIT.md)。原技能、全部 82 个旧操作以及新增长程操作保留，历史研究与验证证据没有迁移或删除。

本次没有替研究者改变科学方向、关闭人工审阅或自动接受 RSI 候选。后续可按真实使用反馈调整两个产品的发布节奏。历史真实模型检查属于其原始版本，本次验证侧重拆分后的功能兼容、依赖来源和打包。

验证结果：Skill 导入固定引擎后的 Windows 全量回归 **188 项通过，0 跳过**，包括宿主重复安装、原有科研运行器、Agent、长程项目、绘图/PPT 和新增依赖同步检查，见 [skill-windows.json](skill-windows.json)。测试后仅订正工具数量文档及更新锁中的来源提交，Python 源文件哈希均未变化。

[保留检查](preservation.json)确认旧版本 430 个跟踪文件全部仍在、26 个技能与 90 个操作保留；拆分未改动引擎逻辑，MemTX 原始文件哈希匹配。原文“18 个原生 Agent 工具”为计数错误，实际是 17 个，现已订正；没有删除工具。
