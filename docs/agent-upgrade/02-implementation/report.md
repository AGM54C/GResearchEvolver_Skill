# Agent 重型化：实现记录

## 为什么与方法

复用 SQLite/CAS、哈希审计链、OS 锁和监督器，减少第二套执行机制带来的恢复歧义。把外部请求、工具副作用与控制器事务分开记录，允许检验中断究竟发生在哪里。

## 实际修改

- 新增原生工具协议，保留 Responses reasoning/加密续接项、Chat tool_call_id、Ollama 工具结果；拒绝截断、重复 ID 和无效 JSON。
- 新增持久 Agent 会话、工具队列、用量账本、瞬时模型错误重试、上下文和执行预算、恢复及人工对账。
- 新增全量能力目录、技能资源分页、材料导入、乐观并发文件写入、完整工具回执分页；原有操作全保留。
- 新增本地中文工作台：目标、配置、预算、阶段报告、问题、精确调用审批、运行中纠偏、产物下载与日志。
- 为每阶段记录解释/依据/局限/待决问题，科研图谱维持节点与类型边；进化提案可引用真实 Agent 报告及反馈。
- 新增源码/选定环境固定、命令与输入快照绑定、确定性全量源码 ZIP 构建和完整性检查。
- 增加明确预算提示、单操作接口查询与带父会话溯源的续接；安装到共享宿主目录后只读取本套注册技能。
- 全库备份/恢复包含 Agent 材料、报告和原始调用目录；完整性检查覆盖 Agent 的 CAS 引用，doctor 报告待恢复会话。结果已经结算而下一次调用尚未开始时的控制器崩溃也可恢复。

## 边界

人类审批入口不暴露为模型可以自动执行的工具。审批本机命令仍意味着信任该命令；同权限恶意进程不在此网关的隔离能力内。源哈希和测试通过不代表科学论断成立。公网认证、多租户权限、服务高可用与大规模运行稳定性尚未实现。

## 真实开发来源

本轮实现由 Codex 会话完成，不是华为云码道开发记录。比赛证明材料应保留后续在码道中真实发生的实现、调试和验证，不回填虚构历史。

## 反馈

新增功能已进入实际验证；用户体验反馈尚待研究者使用后填写。未将测试脚本中的 fixture 审批记为真人科研审阅。
