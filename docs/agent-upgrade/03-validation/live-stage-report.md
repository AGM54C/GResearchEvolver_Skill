## 深入浅出的解释

独立实验单位取决于处理如何独立分配，例如按小鼠分配时通常以小鼠为单位，按笼分配时通常以笼为单位。3只小鼠各测10次不等于30个独立单位，把读数当独立样本就是伪重复，可能低估不确定性。Holm降低多重检验的误报风险，但不能修复伪重复或无效原始p值。本例校正值为0.03、0.06、0.20；若演示使用0.05阈值，只有第一项达到阈值。
