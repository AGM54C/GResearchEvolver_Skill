# rsi-evolver 进化验收 Rubric（验收标准落盘）

> 被 `rsi-evolver` 引用。定义「一轮合格的受控进化」的验收线。
> 各维 1–5 分。**V1 或 V4 = 0 → 本轮进化无效，策略库回滚**。

## V1 独立评价（硬约束，SEAL 红线）
| 分数 | 标准 |
|---|---|
| 5 | `eval-N.json` 的 value/baseline 来自外部（独立执行/外部抽样/隐藏标签/领域规则），数据来源可追溯；非任何 skill 自产分数 |
| 3 | 评价外部但 baseline 选取偏弱 |
| 0 | 评价退化为 self-score（含 autopilot/rsi-evolver 自评分）→ 无效 |

## V2 反思可复核
| 分数 | 标准 |
|---|---|
| 5 | 每条根因判断带轨迹证据（哪一步/哪个产物）；「无明显错误」也给出排查依据 |
| 3 | 根因方向正确但证据链不全 |
| 1 | 只有感觉式总结 |

## V3 经验质量
| 分数 | 标准 |
|---|---|
| 5 | 每条经验含 `skill / failure_mode / 为什么 / 如何应用` 四要素；成功与失败都记 |
| 3 | 四要素有个别缺项 |
| 1 | 模糊的「这样做更好」式建议 |

## V4 门控与回滚（硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 策略库每次变更附 `门控结果 + 回滚点`；无 eval 支持的变更零发生 |
| 3 | 门控执行但个别回滚点缺失 |
| 0 | 存在无门控写入 → 回滚 + 无效 |

## V5 能力边界视角（RLVR）
| 分数 | 标准 |
|---|---|
| 5 | 评价同时报告 pass@1 与 pass@k 视角；「单次通过提升」不冒充「能力边界扩大」 |
| 3 | 有多视角但未区分两类结论 |
| 1 | 只看单次最优 |

## 复现要求

- 每轮进化写 `evolution-<N>.json`：reflect 结论 / eval 来源 / distill 条目 / evolve diff / 门控结果。
- 策略库变更保留 `git tag` 或快照作为回滚点。
