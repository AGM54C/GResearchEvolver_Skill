# style-mimic 验收 rubric

> 画像与应用双段验收。任一 P 档 = 0 → 作废（SKILL.md Gate Check 对齐）。

## P 段（画像质量，Phase 0 验收）

| 档 | 检查项 | 0 分线 |
|---|---|---|
| P1 忠实于样本 | 每特征有 verbatim 例句 + span 出处；判定与例句一致 | 任一特征无例句或例句与判定矛盾 |
| P2 机械可测 | 数值特征（句长/hedging 谱/连接词频次/主被动比）由脚本统计且数值入 trace | 任一数值凭印象填写 / 无脚本口径 |
| P3 四层完整 | 结构/句法/词汇/修辞四层齐全（zh 样本含 §5 特有维度） | 缺层或层内核心特征（hedging 谱/句长分布）缺失 |
| P4 负向核对 | AI-tel 逐项核对完成；样本特有标白名单，其余零注入 | 未做核对 / 全清单照抄未对照样本 |

## A 段（应用质量，Phase 2 验收）

| 档 | 检查项 | 0 分线 |
|---|---|---|
| A1 谱对齐 | hedging 动词谱主档位与画像一致；连接词频次比贴近 | 主档位错位（样本 indicate 为主、生成稿满篇 prove） |
| A2 注入检查 | 生成稿 AI-tel 全部属于样本白名单 | 出现样本不含的 AI-tel |
| A3 红线隔离 | 风格执行前后：数字/引用/claim 锚/未决标记逐项 diff 零变化 | 任一数字或引用被风格化改写 |
| A4 校验量化 | consistency-report 含数值偏差表；超阈值项有修订建议不静默 | 无报告 / 偏差超 30% 未标注 |

## 操作提示

- A3 的 diff 检查：paper-writer 在风格应用前后各存一版正文（`draft-pre-style.md` / `draft.md`），脚本 diff 数字与引用行。
- 双语样本：P3 按 zh 样本追加维度检查；跨语言模仿声明检查（只用语言无关层）。
