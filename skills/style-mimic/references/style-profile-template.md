# 风格画像模板（style-profile-template）

> 四层画像结构。每层特征三件套：**观测方法**（可机械化则给脚本口径）/ **verbatim 例句**（≥1 条，标 span）/ **应用指令**（生成时怎么执行）。数值特征必须由脚本统计并入 trace；禁止凭印象填数值。

## 0. 画像头部（元信息）

```markdown
# 风格画像：<样本名>
- 样本：路径 + 语言（en/zh）+ 篇数
- 提取参数：strength / 提取日期 / 统计脚本口径
- 样本规模：正文词数（en）/ 字数（zh）、章节数——画像置信度声明（样本 <2000 词时标注「小样本，画像置信度低」）
```

## 1. 结构层（Structure）

| 特征 | 观测方法 | 应用指令 |
|---|---|---|
| 章节推进式 | 数章节标题与顺序（Intro→RW→Method→Exp→Concl 或变体） | 生成稿采用同构章节序列 |
| Intro 漏斗模式 | 判类：宽挑战式（A1）/ 部署承诺式（A2）/ 场景失败式（A3）+ pivot 位置 | opener 按样本类型执行 |
| 贡献陈述式 | 判类：枚举式（threefold: (1)(2)(3)）/ 叙述式 / 无显式列表 | 按样本式陈述贡献 |
| 段落长度分布 | 每段句数均值/方差（脚本） | 生成段落句数贴近分布 |
| 图表前向引用密度 | 每千词 "Fig./Table" 频次（脚本） | 前向引用按同密度插入 |

## 2. 句法层（Syntax）

| 特征 | 观测方法 | 应用指令 |
|---|---|---|
| 句长分布 | 均值/标准差/长短句交替模式（脚本：按句切分统计） | balanced：贴近均值；strong：复现交替节奏 |
| 主被动比 | 被动式占比（en: be+V-ed；zh: 被字句）（脚本） | 按样本比例 |
| 名词化度 | -tion/-ment/-ance 密度；中文「性/化/度」密度（脚本） | 按样本密度 |
| 从句嵌套深度（en）/ 流水句长度（zh） | 人工抽 10 句判定层级 | 句式复杂度对齐 |

## 3. 词汇层（Lexis）

| 特征 | 观测方法 | 应用指令 |
|---|---|---|
| **hedging 动词谱**（核心） | 频次谱（脚本）：en suggest/indicate/show/demonstrate/prove/establish；zh 提示/表明/说明/证明/证实 | **谱主档位对齐**：样本以 indicate 为主则生成稿主用 indicate——动词强度不超证据原则与样本谱的交集 |
| 连接词偏好 | 频次比（脚本）：en Yet/However/Nevertheless/Moreover；zh 然而/但/不过/此外 | 按样本频次比选用 |
| 术语与缩写习惯 | 首次定义时机（首次出现即定义 vs 集中在 Intro）；大小写/连字符习惯 | 术语表按样本习惯锁定 |
| 数字报告式 | delta-form（"improves X by 4-7 points"）vs absolute（"reaches 0.91"）占比 | 结果句按样本式报告 |
| 强调词谱 | 显著/markedly/substantial 等频次（脚本） | 按样本，注意与内容红线：结论强度仍由证据定 |

## 4. 修辞层（Rhetoric）

| 特征 | 观测方法 | 应用指令 |
|---|---|---|
| opener 类型（首句） | 判类 A1-A4（借 embodied 分类法） | 首句按样本类型 |
| pivot 习惯 | However/Yet 出现位置（第 1-2 句 vs 段中）；每 gap 几个 pivot | 按样本习惯 |
| 时态习惯 | abstract 时态 / conclusion 时态 / 实验描述时态 | 按样本 |
| 收尾式 | 结论章最后一段模式（贡献复述螺旋 / 局限先行 / 展望式） | 按样本式收尾 |

## 5. 中文特有维度（zh 样本追加）

| 特征 | 观测方法 | 应用指令 |
|---|---|---|
| 把字句/被字句密度 | 频次/千字（脚本） | 按样本 |
| 顿号列举 vs 分号列举 | 频次比 | 按样本 |
| 四字格使用度 | 学术四字格（相辅相成/由此可见）频次 | 适度按样本 |
| 中文学术连接谱 | 因此/因而/进而/综上 频次（脚本） | 按样本 |
| 「我们」句密度 | 首人称句占比 | 按样本（部分中文期刊风格回避首人称） |

## 6. 负向核对区（AI-tel 交叉）

- 逐项过 `ai-tell-catalog.md`：样本含 → 画像照录 + 标 `[样本特有：模仿优先于去味]`；样本不含 → 生成零注入。
- 跨语言模仿（英文样本 → 中文写作）：只用结构层 + hedging 谱语义映射（prove→证明/suggest→提示），句法词汇层不跨语言移植。

## 7. 模板输出骨架

```markdown
# 风格画像：<样本名>
（元信息如 §0）

- 章节推进式：<判定> — 例句："..."（span: §1）— 指令：<...>
（每特征一行三件套）

## 句法层
- 句长：均值 21.3 词 / SD 8.1（脚本 #S1）— 例句：... — 指令：...

## 词汇层
- hedging 谱：indicate×14 / show×9 / demonstrate×4 / prove×1（脚本 #S2）— 例句：... — 指令：主档位 indicate

## 修辞层
...

## 负向核对
- AI-tel 白名单（样本特有）：<...>
- 零注入清单：<其余全部>
```
