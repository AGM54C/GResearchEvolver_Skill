# experiment-replicator 执行验收 Rubric（验收标准落盘）

> 被 `experiment-replicator` 引用。定义「一次合格的实验执行/复现」的验收线。
> 各维 1–5 分。**P3 = 0（粉饰失败）→ 本次执行作废，重跑**。

## P1 环境可复现
| 分数 | 标准 |
|---|---|
| 5 | config/依赖/种子/数据版本全记录；换机按 README 可重跑 |
| 3 | 环境记录基本齐全，个别版本未锁定 |
| 1 | 环境不可追溯，结果无法复现 |

## P2 指标对齐（复现论文时）
| 分数 | 标准 |
|---|---|
| 5 | 与原文数字逐项对齐；每项偏差给出幅度与可能原因 |
| 3 | 主要指标对齐，次要指标缺失 |
| 1 | 数字对不上且无解释 |

## P3 结果如实（硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 成败如实：失败即报失败（exit_code/stderr 原样），负结果完整保留 |
| 3 | 结果如实但个别失败细节被省略 |
| 0 | 任何粉饰（改数、隐藏失败、把跑不通说成跑通）→ 作废 |

## P4 幂等与续传
| 分数 | 标准 |
|---|---|
| 5 | run 目录按 `run-<N>` 隔离；中断后可从断点续跑；重跑不覆盖历史 run |
| 3 | 可续跑但偶有覆盖风险 |
| 1 | 无断点机制，重跑即覆盖 |

## P5 判定回填
| 分数 | 标准 |
|---|---|
| 5 | 按 plan.json 的 `judgement` 规则回填「成立/证伪/部分支持」，规则原文随附 |
| 3 | 有回填但规则引用不全 |
| 1 | 无判定回填 |

## 复现要求

- 每个 run 保留：原始 stdout/stderr、指标 JSON、判定结果三件套。
- 诊断报告必含：与基准偏差、失败 run 清单、环境漂移风险。
