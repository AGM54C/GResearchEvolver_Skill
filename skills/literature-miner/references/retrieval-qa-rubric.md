# literature-miner 检索质量 Rubric（验收标准落盘）

> 被 `literature-miner` 引用。定义「一次合格的文献检索」的验收线。
> 各维 1–5 分。**R2 = 0（编造文献）→ 整次检索作废重做，产物全部丢弃**。

## R1 检索式覆盖
| 分数 | 标准 |
|---|---|
| 5 | ≥3 个检索式，明确覆盖「综述/方法/评测」三类并标注意图 |
| 3 | ≥3 个检索式但覆盖面偏向单一类型 |
| 1 | 单一检索式直接开查 |

## R2 真实性（硬约束，反捏造）
| 分数 | 标准 |
|---|---|
| 5 | 每条结果带真实 DOI/arXiv ID/URL；`raw/` 原始返回完整可复核；抽查全部通过 |
| 3 | ID 齐全但 raw/ 部分缺失（≤1 源） |
| 0 | 发现任何 1 条编造（ID 不存在/题目对不上）→ 整次作废 |

## R3 去重正确性
| 分数 | 标准 |
|---|---|
| 5 | 按 DOI > arXiv ID > 规范化 title 优先级去重，抽样零误并/漏并 |
| 3 | 个别误并（同文不同 ID 已尽力归并） |
| 1 | 大量重复条目 |

## R4 相关性排序
| 分数 | 标准 |
|---|---|
| 5 | Top-10 抽样与 query 高相关；排序依据（匹配度/引用/年份）可解释 |
| 3 | Top-10 过半相关 |
| 1 | 排序与相关性脱节 |

## R5 新颖性增量
| 分数 | 标准 |
|---|---|
| 5 | 优先召回已有论断图未覆盖的新证据，并标注增量 |
| 3 | 有增量标注但未优先 |
| 1 | 全部为已入库文献 |

## R6 全文获取如实标注
| 分数 | 标准 |
|---|---|
| 5 | 每条标注 `fulltext / abstract_only / paywalled / EVIDENCE_MISSING`，无虚标 |
| 3 | 个别状态不准 |
| 1 | 大面积虚标（如 paywalled 标成 fulltext） |

## 复现要求

- 检索失败：读 stderr → 换源重试（≤2 次原样）→ 降级 OpenAlex 兜底 → 仍失败输出 `EVIDENCE_MISSING`，禁止填充。
- 诊断报告须给出：各源命中率、去重前后数量、全文获取率、空结果清单。
