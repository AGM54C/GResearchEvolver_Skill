# 诊断报告模板（共享定义）

> 被所有 L2 产出 skill 引用。核心原则：**错误有明确含义，判断有可复核依据，真值未知就明说。**

## 统一模板（五列）

```markdown
## 诊断报告（diagnosis）
| 条目 | 判断 | 置信度 | 依据 | 未决项 |
|---|---|---|---|---|
| <结论1> | 成立/存疑/错误 | 高/中/低 | <claim_id / run 号 / span> | <真值未知部分> |
```

## 强制项

1. `依据` 必须可追溯（claim_id、实验 run 号、原文 span、真实 URL/DOI）。
2. 置信度附证据与未确定因素；高/中/低只能作界面摘要，不是校准概率。保留科学语境中合理的“可能”“尚未确定”，不要为统一标签删除不确定性。
3. 真值未知时 `未决项` 必须显式写出，**不得留空，不得假装已知**。

## 分级支持标签（判定证据强度时用）

| 标签 | 含义 |
|---|---|
| `strong-support` | 直接实验/数据支持，条件对齐 |
| `partial-support` | 部分支持，条件不完全对齐 |
| `background-support` | 仅背景/动机级别，非证据 |
| `EVIDENCE_MISSING` | 无证据，禁止写成已证 |

> 主要危险不是 AI 不会写，而是它会**自信地写错**。给出结构化方式说「证据不足」，比相信它主动承认不确定更可靠。
