# 选图、科学含义与审阅

## 用问题选择表达

| 要回答的问题 | 起点 | 需保留的含义 |
|---|---|---|
| 大小或组间差异 | 原始点＋估计量/区间，必要时箱线 | 独立单位、样本量、配对/重复测量；小样本不隐藏原始点 |
| 连续过程 | 线或点＋区间 | 时间顺序、缺失间断、插值/平滑是否真实执行；类别不随意连线 |
| 分布 | 点、ECDF、直方、箱线或小提琴 | bin/带宽、极端值、删失；密度形状需要足够数据 |
| 两量关联 | 散点、密度或六边形分箱 | 过绘、尺度、独立单位；关联不推出因果 |
| 高维比较 | 热图/小多图 | 共享色标、标准化参考、缺失颜色、变量量纲 |
| 效应与不确定性 | 点区间/森林图 | 零效应参照、效应尺度、区间含义、估计来源 |
| 方法或机制 | 可编辑节点/边＋具体例子 | 流程、数据依赖、关联、因果、假设应有不同表达 |

没有通用最优图型。用户指定的图型若可能造成误读，解释具体原因并给可比较备选；用户已明确选择时遵照执行并保留必要科学标注，不反复要求确认。

## 数据与图像

- 区分 SD、SEM、CI、可信区间和预测区间；说明估计方法和独立采样单位。统计工具另行执行，绘图工具不凭数据形状编造 p 值。
- 柱的长度通常从零开始；点图可用非零范围但应表达上下文。声明对数/截断/轴反转，禁止为美观选择性隐藏异常点。
- 保留原始值与变换代码。平滑、标准化、排除、抖动的方式与随机种子记录在 spec/图注；不得将平滑线标为原始观测。
- 原始实验图像保留副本与采集尺度。裁剪、拼接、伪彩、整图亮度调整应可追溯；局部擦除、生成填充不能伪装成观测。
- 生图适合明确标为示意的概念素材；精确拓扑、公式和数据由可编辑的确定性元素表达。

## 视觉 QA

检查最终尺寸下的轴/标签/色标、单位与上下标、图例遮挡、panel 编号、共享尺度、字体替代、文本溢出和原图比例。颜色之外增加线型、符号、直接标签等编码；灰度预览只是辅助检查。记录 alt text 和可访问的数据替代。

机器检查通过后仍实际打开导出图。记录“未检查/发现问题/已修复并重渲”，不要填统一高分。节点不重叠不能保证箭头没有穿过其他节点，源引文存在不能证明关系方向正确。

期刊栏宽、分辨率、字体、矢量/位图、色彩空间分别核对当前官方指南。提供检查时间和链接，通用建议不冒充期刊硬要求。

需要记录逐项结果时使用 [图表审阅记录](figure-qa-rubric.md)。
