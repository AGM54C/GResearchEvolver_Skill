# 图表审阅记录

与 [设计与质量检查](design-and-review.md) 配合使用。每项记录 passed / failed / pending / not-applicable、证据位置、检查者与产物哈希；不合并成 AI 自评“科研质量总分”。

| 层面 | 检查内容 | 判断责任 |
|---|---|---|
| 数据与方法 | 数据、变换、单位、缺失、独立样本单位、区间和统计口径可追溯；没有虚构点或显著性 | 机械核对加领域审查 |
| 科学含义 | 图支持的论断、未支持的推断、替代解释；箭头是否代表流程、相关或因果 | 研究者 |
| 编码与风格 | 图型是否适合问题；轴/色标、跨面板比较、图例、灰度、字号与参考风格 | 机器辅助，研究者取舍 |
| 实际导出 | 打开 PDF/SVG/PNG；箭头、中文、公式、裁切、标签和比例与源一致 | 真实渲染和逐图检查 |
| 来源与回接 | 正文图号、图注、数据、代码、来源和审阅对应同一版本 | 机械核对 |
| 理解与采用 | 能否解释结果及限制；哪些意见已落实，哪些有争议 | 真实研究者反馈 |

数据不符或有误导性科学表达时修订，并保留原失败记录。尚未审阅的图可交付为草稿，不能标记为已获人工采用。style-match 仅在用户指定参考风格时评价，不能压过科学准确性。

复现记录应覆盖输入、代码、spec、依赖、字体和导出工具。按已声明口径重建内容，不要求不同环境生成相同文件字节。机器检查通过不能替代图像检查、专业判断或读者理解测试。
