# figure-mimic 图表质量 Rubric

> 被 `figure-mimic` 引用。**F2 或 F3 = 0 → 图作废重做。**

## F1 画像质量
| 分数 | 标准 |
|---|---|
| 5 | 五层特征全观测（取色/计数可机械化）；每特征有 figure-id 例证与频率 |
| 3 | 缺一层或例证不全（<80% 特征有指针） |
| 1 | 凭印象描述风格（「大概蓝色系」无 hex 无例证） |

## F2 数据真实（硬约束，反捏造视觉层延伸）
| 分数 | 标准 |
|---|---|
| 5 | 数据图数据点 100% 来自 data_source；代码随图归档可复现 |
| 3 | 数据真实但代码未归档（不可复现） |
| 0 | 生图模型画数据图 / 数据点无源 / 坐标值与账本不符 → 作废 |

## F3 人工确认环（概念图硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 每张概念图经 H2 确认（内容准确+风格相似双指标）或诚实降级并记录 |
| 3 | 确认记录不完整（确认了但未记指标） |
| 0 | 未确认的生图直接入稿 → 作废 |

## F4 回接对账
| 分数 | 标准 |
|---|---|
| 5 | figure-map 双向平衡；正文引用 ↔ 图文件 ↔ 数据源/确认记录全闭环 |
| 3 | 平衡但个别映射证据弱 |
| 1 | 幽灵图（正文引了图不存在）未处理 |

## F5 风格执行
| 分数 | 标准 |
|---|---|
| 5 | 配色/布局/标注按画像执行（逐层对照）；样本零使用的元素未混入 |
| 3 | 主层执行但细节漂移（标号式样/图例位置） |
| 1 | 风格与画像无关（自由发挥） |

## 复现要求

- E6：同图集 + 同口径 → 同画像；同数据 + 同画像 → 数据图代码一致；
- figure-report 含确认记录（或降级声明）与对账统计。
