# 科研图表与示意图

从科学问题、读者和证据出发选择视觉编码。保留 figure-mimic 名称以兼容已有工作流；不要求用户提供参考图，也不限定为模仿风格。使用参考图时记录可借鉴的配色、排版与编码，不复制其数据、标识或未经许可的素材。

## 先确定内容与路线

从已有上下文提取目标论点、原始数据/图像、独立样本单位、单位、缺失值、变换、误差定义、最终物理尺寸和用途。关键缺失影响科学解释时再问。期刊规范应查目标期刊当前官方页面；没有明确期刊时使用通用尺寸并注明，不能把历史预设说成投稿合规。

提交简短 brief：要回答的问题、证据、推荐图型、备选与代价。研究者确定核心主张、图型取舍、信息密度和是否改方向；已明确的选择直接沿用。详细选图、编码和审阅见 [设计与质量检查](references/design-and-review.md)。

指定参考风格时使用 [风格画像模板](references/figure-style-template.md)，记录观测、图号例证和应用指令；已有 samples/figure_type/data_source/gen_endpoint/out_dir 参数仍作为宿主输入。samples 不再必填，概念图也不再依赖生图端点。

| 情况 | 实现路线 |
|---|---|
| 表格数据、统计图、多面板 | Matplotlib/Seaborn/Plotly；保留数据、变换代码与环境。常见 CSV 图可用 scripts/build_figure.py |
| 方法框架、流程、关系图 | 优先原生 SVG/draw.io/TikZ/Mermaid；简单显式节点与边用 scripts/build_diagram.py，复杂图由宿主编写可编辑源文件 |
| 科学图像、显微/遥感图 | 保留原始像素、标尺和采集信息，记录裁剪及整图处理；不生成、修补或抹去实验结构 |
| 概念插画 | 可以调用宿主实际可用的生图工具；记录端点、提示、输入与失败。文字、精确数值和证据图用确定性工具叠加；没有工具时交付可编辑图或明确的草稿 |
| 交互探索 | 提供可访问数据和静态后备；交互图与出版图分别检查 |

数据点、区间、显著性和坐标必须来自可追溯材料。没有统计结果时不加显著性星号；重复测量不能按行数冒充独立样本量。生图不得重绘定量结果或替换科学原始图像。标注“示意/模拟”的数据仅用于明确要求的解释或测试。

## 生成、检查与交付

1. 根据 brief 编写 source-bound spec 或可复现绘图代码。使用新输出目录，不覆盖原始数据或已有版本。
2. 数据图检查原始点、缺失间断、单位/轴范围、区间含义、色标与跨面板可比性。示意图检查节点、箭头方向、关系类型和文字；来源关联不等于因果关系。
3. 导出 PDF/SVG 和 PNG 预览；按需要输出 TIFF。按最终刊载尺寸检查字号、字体、裁切、图例、留白和冗余编码。显示灰度预览，但不把它视为完整色觉可访问性测试。
4. 实际打开图像检查，记录具体缺陷、修正与重渲。可先在声明预算内做两轮局部修复；科学主张或编码策略改变时返回研究者判断，不能靠降低阈值结束循环。
5. 交付可编辑源/生成代码、数据引用和哈希、图注/alt text、产物及检查报告。解释为什么用此图、允许得出什么结论、哪些不能得出。运行命令和 spec 见 [工具接口](references/tools.md)。

生成脚本不证明论断成立，也不保证所有标签没有重叠。不能将未执行的渲染、人工审阅或期刊检查标为通过。

与论文联动时沿用现有 paper-state.json 的 claim_id/run/数字账本，维护 figure-map.json 中的图号、正文位置、文件版本、数据源和审阅记录；双向检查正文引用与文件。独立画图任务无需创建空论文状态。

## 人机协作与受控进化

遵循 [阶段报告与人工反馈](../_shared/human-guided-research.md) 和 [视觉工作的人类监督协议](../_shared/visual-research.md)。在 brief、预览和交付阶段生成 report.md；使用真实 stage-feedback 处理 approve/revise/explain/stop/comment。版本、图号、报告和意见进入科研节点/关系边，不以摘要覆盖原证据。

改进目标为 `skill:figure-mimic`。从具体渲染失败、误读或研究者反馈提出候选，使用 `capability-freeze/propose/evaluate/review/activate` 比较；科学保真、可靠性、清晰度、成本和人的偏好分别记录。AI 不得自行扩大科学主张、更改研究方向、修改评估标准或代替研究者批准。评分通过只是人工采用的前提，新版本只用于明确绑定的新运行。
