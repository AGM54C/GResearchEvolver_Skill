# idea-forge 适应度 Rubric（验收标准落盘）

> 被 `idea-forge` 引用。把「好 IDEA」从感觉变成可打分、可复现的 artifact。
> 综合适应度 = Σ(权重 × 分数)，各维 1–5 分。**F3 或 F4 = 0 → 个体直接淘汰**。

## 六维打分标准

### F1 新颖性（权重 0.25）
| 分数 | 标准 |
|---|---|
| 5 | 与方法近邻无重叠，填补明确 gap（gap-map 中标注的空缺处） |
| 3 | 与已有方法有显著差异，但同源可辨 |
| 1 | 直接重复已有方法（AskChem/SciFact/SEAL/AIDE² 等）的重新包装 |

### F2 可行性（权重 0.20）
| 分数 | 标准 |
|---|---|
| 5 | 数据可下载、方法可落地、资源预算内 |
| 3 | 需申请权限或部分依赖未知 |
| 1 | 数据/方法不可得，纯设想 |

### F3 评价边界（权重 0.20，硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 明确写出「真值未知时评什么局部环节、缺什么不可评、如何报覆盖率/误改/成本」 |
| 3 | 有边界但未说清缺什么 |
| 0 | 无评价边界 |

### F4 强基线（权重 0.15，硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 同预算下可比方法/规则明确，且可执行 |
| 3 | 有基线但非强基线（过弱） |
| 0 | 无强基线 |

### F5 可证伪性（权重 0.10）
| 分数 | 标准 |
|---|---|
| 5 | 有明确反驳条件（什么结果能推翻它） |
| 2 | 模糊 |
| 1 | 不可证伪 |

### F6 成本（权重 0.10）
| 分数 | 标准 |
|---|---|
| 5 | 低成本高杠杆（小范围试验即可定贡献） |
| 3 | 中等 |
| 1 | 需大量资源 |

## 遗传算子

- **选择**：锦标赛 k=3 + 精英保留（前 elites 名）。
- **交叉**：问题×方法、方法×数据、评估×诊断 组合。
- **变异**：改条件 / 换方法 / 调粒度 / 翻转假设；变异率随代数衰减。

## 收敛判定

- 达到 `generations` 代，或连续 2 代最优综合分无提升。

## 复现要求

- 每代写 `gen-<g>.json`（个体 ID + 六维分 + 淘汰理由），保证进化历程可复核。
- 记录 `restarts` 次不同种子，报告各次最优，取最优的一次。
