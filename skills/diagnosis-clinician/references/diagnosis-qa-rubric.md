# diagnosis-clinician 诊断报告 Rubric（验收标准落盘）

> 被 `diagnosis-clinician` 引用。定义「一份合格的诊断报告」的验收线。
> 各维 1–5 分。**D1 或 D2 = 0 → 报告作废重做，不得交付**。

## D1 依据可追溯（硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 报告每行 `依据` 均可追溯到 claim_id / run 号 / span，抽查 100% 命中 |
| 3 | 个别依据指向模糊但方向正确 |
| 0 | 存在无依据的强制正误标签 → 作废 |

## D2 规则层裁决（硬约束，非图连通）
| 分数 | 标准 |
|---|---|
| 5 | 每条依据经过来源角色/有效期/共同依赖三查；无「图路径连通即支持」的越界结论 |
| 3 | 三查执行但个别漏项 |
| 0 | 以图连通作为支持依据 → 作废 |

## D3 失败条件分类与分级
| 分数 | 标准 |
|---|---|
| 5 | 每个错误落到第 2 节五类失败条件之一；L5 输出四类分级（决定性错误/传播后果/被补偿失败/计划性冗余），勿把传播后果当起因（DeFA/DiLLS） |
| 3 | 分类正确但未区分决定性/传播 |
| 1 | 归因停留在表面症状 |

## D4 干预分级可检验（DoVer + AGDebugger）
| 分数 | 标准 |
|---|---|
| 5 | 每个决定性错误给出 I1–I3 分级干预候选（由轻到重 + 失败条件→干预映射，见 `../../_shared/intervention-protocol.md` §2），每项带「重跑后应观察到什么」的验证条件；标注「修好 ≠ 唯一根因」 |
| 3 | 有干预但未分级或验证条件模糊 |
| 1 | 只给结论不给干预 |

## D5 未决项显式
| 分数 | 标准 |
|---|---|
| 5 | 真值未知部分全部落入 `未决项` 列；判断/置信度不含虚高 |
| 3 | 个别未决项被写成确定 |
| 1 | 大量「未决」写成「确定」 |

## D6 能力/机制边界（level=agent+llm 时加评）
| 分数 | 标准 |
|---|---|
| 5 | 不用事后信息反推当时必然错误；探针读不出 ≠ 不存在的边界被遵守 |
| 3 | 边界表述基本正确，个别越界 |
| 1 | 用结果反推原因（事后偏差） |

## D7 快速定位管线完整性（L1–L6）
| 分数 | 标准 |
|---|---|
| 5 | L1–L6 齐备：分层重组（缺层时标注「结构为推断」）+ 依赖图落盘 deps.json（protocol/semantic/claim 三类边）+ 分段候选召回（每个候选带理由+失败条件类别，召回阶段不收敛到单一假设）+ 失败传播（上游来源/下游影响/共同前件/被补偿）+ L5 四类分级 + 决定性错误绑定责任 agent 与证据 span |
| 3 | 管线主体完整但个别环节缺失（如无传播分析、候选无理由） |
| 1 | 从症状直接跳到结论，无定位过程 |

## D8 干预判定记录（有干预重跑执行时加评）
| 分数 | 标准 |
|---|---|
| 5 | 每个已执行干预有判定四类（Validated ≥2/3 重复成功 / Partially Validated / Refuted / Inconclusive）；agent 未遵循干预单列为 Inconclusive 而非计入成败；Progress Made = (A(τ̃)−A(τ))/K 按 manifest `pipelines` 里程碑数计算 |
| 3 | 有判定但无遵循记录或 PM 未量化 |
| 1 | 只记「修好了/没修好」 |

## 复现要求

- 五列表 + 决定性错误表缺表即不达标。
- 干预重跑 fork 新记录，**原轨迹完整保留**可对比（good-enough checkpoint，见 `../../_shared/intervention-protocol.md` §3）。
- 同一诊断输入重跑，核心结论（判断 + 失败条件 + 决定性错误）应稳定一致。
