# reviewer-panel 评审质量 Rubric

> 被 `reviewer-panel` 引用。**R2 或 R3 = 0 → 评审作废重跑。**

## R1 人格与分配质量
| 分数 | 标准 |
|---|---|
| 5 | overlay 由论文子领域派生且分配依据落盘；覆盖并集 = 全部子领域，核心域 ≥2 人 |
| 3 | overlay 部分脱靶（某子领域无人覆盖）但已声明盲区 |
| 1 | 人格与论文领域无关 / 固定人名库硬套 |

## R2 锚回接真实（硬约束，反捏造）
| 分数 | 标准 |
|---|---|
| 5 | 每条 fatal/major 定位到原文 span 且问题真实存在；uncertain 疑点不升格为缺陷 |
| 3 | 个别 major 定位模糊（章节对但段落错） |
| 0 | 任何 fatal 指向不存在的问题（评审幻觉）→ 作废 |

## R3 声明-证据矩阵完整（硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 全文论断逐条三态标注（有锚支撑/锚弱/无锚）；矩阵随 review.json 落盘 |
| 3 | 主张性论断覆盖但引用性论断漏标 |
| 0 | 矩阵缺失或抽查发现大面积漏判 → 作废 |

## R4 分级与建设性
| 分数 | 标准 |
|---|---|
| 5 | fatal/major/minor 分级准确；每条附可执行建议；冲突并陈未合并 |
| 3 | 分级大致正确但个别 fatal 混入 major |
| 1 | 全部平铺无分级 / 冲突被平均化 |

## R5 诚实边界
| 分数 | 标准 |
|---|---|
| 5 | 报告头部含模拟评审声明；harsh 模式用途显式标注 |
| 3 | 声明存在但位置不显眼 |
| 1 | 无声明，评审分数被呈现为决策依据 |

## 复现要求

- E6 幂等：同稿 + 同参数 → 同人格档案 + 同分配（人格种子 = 标题+子领域+参数，落盘 personas.md）；
- review.json 结构化字段完整（reviewer/dimension/severity/location/issue/suggestion/claim_ref），可被 diagnosis-clinician 机读消费。
