# paper-writer 成稿质量 Rubric（验收标准落盘）

> 被 `paper-writer` 引用。定义「一篇合格的研究文稿」的验收线。
> 各维 1–5 分。**W2 或 W3 = 0 → 成稿作废重写；启用风格画像时 W6 = 0 同样作废**。

## W1 证据对齐
| 分数 | 标准 |
|---|---|
| 5 | 每个事实性陈述可溯源到 claim_id / run 号；无来源的陈述已显式标注为推测 |
| 3 | 个别陈述溯源缺失（<10%） |
| 1 | 大量陈述无来源 |

## W2 未决不写死（硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 诊断报告中「存疑/未决」的内容在正文一律保持限定语（如「在 X 条件下」「待复核」）；无虚高确定性 |
| 3 | 个别存疑内容被写成确定（≤2 处） |
| 0 | 系统性地把未决写成确定 → 作废 |

## W3 引用真实（硬约束，反捏造）
| 分数 | 标准 |
|---|---|
| 5 | 全部引用与论断图/文献清单一一对应；无编造引文 |
| 3 | 引文真实但个别页码/出处不准 |
| 0 | 任何 1 条编造引用 → 作废 |

## W4 章节完整性
| 分数 | 标准 |
|---|---|
| 5 | Phase 0 产物清单全实现；方法/实验/局限/未决项各就各位 |
| 3 | 缺次要小节但主线完整 |
| 1 | 核心章节缺失 |

## W5 跨章一致性
| 分数 | 标准 |
|---|---|
| 5 | 数字/结论/术语跨章节一致；与 plan.json 的 judgement 一致；状态卡（paper-state.json）数字账本覆盖全文且每条有出处 |
| 3 | 个别数字不一致但已标注勘误；或账本覆盖不全（<90% 数字登记） |
| 1 | 摘要与正文结论矛盾 |

## W7 章节迭代协调
| 分数 | 标准 |
|---|---|
| 5 | 按信息依赖序逐章起草（状态卡先建后用）；不一致项回流修订对应章节，迭代 ≤2 轮；迭代记录留存 |
| 3 | 一次组装但状态卡齐全（未触发迭代或迭代记录缺失） |
| 1 | 无状态卡的自由组装（长文连贯无机制保障） |

## 复现要求

- 成稿前跑一致性检查（Phase 2），检查记录随稿留存。
- 诊断报告须给出：溯源覆盖率、未决项清单、一致性检查结果。
- 启用画像时：双版本（基线稿/风格执行稿）与一致性报告一并留存，红线 diff 记录可复算。
- 迭代记录（轮数/回流修订清单/未解决冲突）随稿归档，未解决冲突不得静默。
