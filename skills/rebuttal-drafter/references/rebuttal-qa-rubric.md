# rebuttal-drafter 回应质量 Rubric

> 被 `rebuttal-drafter` 引用。**B2 或 B3 = 0 → 草稿作废重写。**

## B1 覆盖完整
| 分数 | 标准 |
|---|---|
| 5 | 每条原子意见有回应（含让步条目的显式承认）；拆原子无遗漏 |
| 3 | 个别复合意见未拆全（回应了主问漏了附带问） |
| 1 | 整条意见被跳过 |

## B2 证据锚完整（硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 每个反驳段有 run 号/claim_id/文献指针且 ledger 对账平衡；无锚条目全部落在让步/补实验档 |
| 3 | 对账平衡但个别指针证据弱（指向存在但相关性需人工确认） |
| 0 | 任何反驳段无证据支撑仍写成反驳 → 作废 |

## B3 无编造（硬约束，反捏造延伸）
| 分数 | 标准 |
|---|---|
| 5 | 数字全部与 runs/成稿对账一致；无虚构「实验进行中」；未决结论未升级 |
| 3 | 无编造但个别数字转录误差（标勘误可修） |
| 0 | 任何编造数字 / 虚构承诺 / 未决升级 → 作废 |

## B4 分档准确
| 分数 | 标准 |
|---|---|
| 5 | 可反驳/需补实验/应让步三档判定与证据库状态一致；「需补实验」全部回接到已存在 plan |
| 3 | 个别边界条目档位存疑（已给 H1 选项） |
| 1 | 明明有证据却建议让步（怯战）/ 无证据却硬反驳（冒进） |

## B5 惯例与语气
| 分数 | 标准 |
|---|---|
| 5 | venue 字数/结构/语气惯例符合；对事不对人；cover letter 无 over-claiming |
| 3 | 结构对但语气偶硬（可修） |
| 1 | 超字数 / 攻击性语气 / cover letter 夸大 |

## 复现要求

- E6 幂等：同评审 + 同证据库 → 同 triage 分布与档位数；
- rebuttal-ledger.md 证据指针全部可 grep 回接；dangling_ref 条目已降级让步。
