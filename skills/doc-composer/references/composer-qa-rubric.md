# doc-composer 输出质量 Rubric

> 被 `doc-composer` 引用。**C2 = 0 → 作废重写。**

## C1 断言登记完整
| 分数 | 标准 |
|---|---|
| 5 | 稿内全部可验证断言入登记表（数值/强度/证据指针三列齐） |
| 3 | 主断言覆盖但次要断言漏登（<80%） |
| 1 | 无登记表直接写稿 |

## C2 真实性零升格（硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 数值精度未升格；结论强度未升格（初步≠证明）；未决保留限定或删；钩子不虚构源外声称 |
| 3 | 个别措辞偏热但断言本身有据（可修） |
| 0 | 任何数字夸大 / 未决写死 / 钩子虚构 → 作废 |

## C3 形态契合
| 分数 | 标准 |
|---|---|
| 5 | 按模板骨架；长度合规；标签/链接/分点形态正确 |
| 3 | 骨架对但形态细节生硬（标签堆砌/分点过密） |
| 1 | 形态错位（小红书稿写成摘要腔） |

## C4 传播力
| 分数 | 标准 |
|---|---|
| 5 | 钩子真实有力（收益点明确）；收尾可信度设计（局限/适用条件）；发布建议具体 |
| 3 | 平实无害但无记忆点 |
| 1 | 靠夸大制造的「传播力」（C2 已违规） |

## C5 跨形态一致
| 分数 | 标准 |
|---|---|
| 5 | 同源多形态产出时数字/结论互检一致 |
| 3 | 单形态产出（不适用） |
| 1 | 两形态同一数字不同值 |

## 复现要求

- E6：同 source + 同 form + 同 audience → 同稿；
- claims-ledger.md 随稿归档（发布后可回溯核对）。
