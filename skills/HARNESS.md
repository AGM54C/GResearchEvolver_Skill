# GResearch runtime v2

本文件规定软件实际行为，替代 v1 的不可执行承诺。规则随完整安装进入 skills 根目录。

## 执行与证据

运行由显式 DAG manifest 固化，stage ID/输出路径按版本唯一。输入快照、真实 argv、环境版本/变量名、原始 stdout/stderr、退出码、时间、输出哈希写入 SQLite 事件记录与内容寻址对象库。只有实际执行或明确 host submission 才标完成；host submission 不代表科学验证。

可恢复的是受管文件与配置。随机种子不使模型、GPU 或远程服务确定；外部数据库/仪器状态另行快照。复现报告说明恢复质量、环境与测量偏差，不承诺全程确定性复现。

## 人的介入与授权

用户既有授权持续有效；本地可逆研究工作直接推进。manifest 的 effects、ssh_hosts、预算表达本次授权，不能由模型伪造批准。外部发布/不可逆写入需具体范围授权，external_write 绑定 stage digest；只在尚缺授权时提出问题。

pause 在阶段边界生效；cancel 尝试终止受管本地进程树；fork 保留父运行并恢复干预前工作区文件，重跑显式依赖后代。人可批注、改变受影响阶段配置、确认/驳回语义对齐；模型摘要不是隐藏思维或因果真相。暂停不自动回滚外部作用。

## 失败、预算和队列

缺失/篡改输入、无新输出、无效 JSON、非零退出、超时分别记录。独立阶段可继续；依赖失败保持阻塞。只有预先声明幂等和 transient exit code 才有限重试（至多 2 次）。时间限制覆盖当前阶段，成本按声明预留，包括重试；不宣称能精确执行云服务计费上限。

队列按优先级、CPU/GPU 声明容量选取任务；资源约束是合作式调度，不是操作系统 GPU 配额。SSH 需要专用远程 cwd，传输显式文件；停止本地 SSH 客户端不能保证远程后代停止，需站点调度器取消和人工核实。

## RSI

冻结协议与外部评分器之后才实跑 candidate/incumbent。任务级配对、回归/保护检查/成本/覆盖/复用次数门槛通过才更新完整策略指针；平局保留，失败可回滚。自写测试和自身评价属于开发信号，不独立批准提升。final 集不参与提升。

本地文件哈希和事件链检测意外变化，不提供同权限攻击者无法篡改的安全封印。策略与评分器需可信；对抗候选要求另一个权限域的外部验收服务。bootstrap 门槛近似有效，固定任务反复自适应使用仍会过拟合。

## 归档与日志

归档包含当前产物原字节、历史 checkpoint 对象、manifest、状态与事件片段，写临时目录后原子 rename 并带 .done digest。无科研状态变化时重归档 no-op。事件链为全局链，单 run 归档保留的是片段；全链在源 Store 验证。旧档不改写，纠错另记。

原始命令/日志可能含研究数据或调用程序自行打印的秘密。密钥应经环境变量引用；runtime 不声称能自动识别和清洗任意日志。导出前按实际分享范围审查。

## 科学验收

哈希正确、引用存在、编译通过、程序成功、模型共识，都不等于结论为真。保留 source→data→code→result→claim 链，独立重算关键结果，语义裁决附证据和反证。负结果、未决、计划中和不适用应分别记录。
