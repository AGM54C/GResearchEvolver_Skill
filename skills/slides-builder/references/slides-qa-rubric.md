# 科研演示审阅记录

与 [演示工作流](presentation-workflow.md) 配合使用。每项记录 passed / failed / pending / not-applicable、页号/对象、依据、检查者和文件版本；不使用 AI 审美总分替代研究者接受。

| 层面 | 检查内容 | 判断责任 |
|---|---|---|
| 科学叙事 | 问题、证据、主张和限制相称；推测有标记；没有为强化标题而删限定 | 研究者 |
| 数据与引文 | 数字、图表、论断、来源和讲稿一致；原文报告与解释分开 | 机械核对加语义审查 |
| 结构与时间 | 页序服务于受众和目标；主报告与备份页分开计时；无统一页数上限 | 研究者决定，工具核对 |
| 讲解与讨论 | notes 说明怎么讲、前提、转场和未决项；长度由内容与时间决定 | 研究者或试讲反馈 |
| 文件与模板 | 可打开、对象可编辑程度明确；没有模板残留；未改部件保留 | 文件检查 |
| 实际渲染 | PowerPoint/LibreOffice 逐页检查字体、裁切、遮挡、公式、图例与投影可读性 | 真实渲染和逐页检查 |
| 采用与意见 | 反馈绑定当前页/对象/论断；修订、解释和拒绝均留记录 | 真实研究者 |

论断/数字失真必须修订；未做的渲染和专业审查保持 pending。修订后检查当前版本，不将旧版本批准移用到新文件。保存可复现来源、构建/修改脚本、slides-ledger、讲稿与报告；文件检查不证明观众理解有所提高。
