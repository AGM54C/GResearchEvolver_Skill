# slides-builder 演示质量 Rubric

> 被 `slides-builder` 引用。**S2 = 0 → 作废重做。**

## S1 论点骨架
| 分数 | 标准 |
|---|---|
| 5 | 一页一论点，标题结论式；无粘贴大段文字页；每页 speaker notes（40-60 字） |
| 3 | 结构对但个别页要点堆砌（>6 条）或 notes 缺 |
| 1 | 正文压缩粘贴式 slides |

## S2 数字账本回接（硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 页内数字 100% 回接 paper-state.json 账本；slides-ledger 对账平衡 |
| 3 | 回接但个别映射弱（数字对但出处标注泛） |
| 0 | 任何无源数字 / 数字与账本不符 → 作废 |

## S3 未决标注
| 分数 | 标准 |
|---|---|
| 5 | 未决结论页显式「（初步/待验证）」；局限页诚实存在（defense 模式） |
| 3 | 个别未决标注遗漏但 ledger 中可查 |
| 1 | 未决被写成确定 |

## S4 结构合规
| 分数 | 标准 |
|---|---|
| 5 | 按 mode 模板页序；页数合规（defense ≤15）；图引用经 figure-map |
| 3 | 页序小偏差或超页 1-2 页 |
| 1 | 模板错乱 / 幽灵图引用 |

## S5 讲稿质量
| 分数 | 标准 |
|---|---|
| 5 | notes 是「这页怎么讲」的口语提示（非要点复读）；答辩模式含预期 QA 提示页 |
| 3 | notes 复读要点 |
| 1 | 无 notes |

## 复现要求

- E6：同 source + 同 mode → 同结构（pptx 脚本可重跑）；
- slides-ledger.md 随稿归档。
