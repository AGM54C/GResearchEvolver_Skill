# latex-adaptor 格式化质量 Rubric

> 被 `latex-adaptor` 引用。**L2 或 L3 = 0 → 转换作废重做。**

## L1 模板合规
| 分数 | 标准 |
|---|---|
| 5 | 模板来源明确（user/官方确认/generic 标注三态之一）；结构符合 venue 规范 |
| 3 | generic 骨架但未标注，或结构小偏差（标题深度/字号） |
| 1 | 伪装官方模板 / 结构错乱 |

## L2 红线零变化（硬约束）
| 分数 | 标准 |
|---|---|
| 5 | 数字/测量值/样本量逐项 diff 零变化；未决标记显式保留；scope 限定无丢失 |
| 3 | 红线零变化但 diff 报告缺失 |
| 0 | 任何数字被改动 / 未决标记消失 → 作废 |

## L3 引用可回接（硬约束，反捏造延伸）
| 分数 | 标准 |
|---|---|
| 5 | cite-map 三向对账平衡；无幽灵/无孤儿/无锚引用已标注 |
| 3 | 对账平衡但个别映射证据弱（如 back_by 指向泛条目） |
| 0 | 幽灵引用未处理 / bib 含编造字段 → 作废 |

## L4 编译诚实
| 分数 | 标准 |
|---|---|
| 5 | PDF 编译通过；或 skipped_no_env 显式声明 + 编译说明完整 |
| 3 | 编译通过但有未记录的手工修复 |
| 1 | 编译失败被静默忽略 / 假装编译过 |

## L5 排版质量
| 分数 | 标准 |
|---|---|
| 5 | booktabs 规范表；公式编号正确；无溢出框（overfull）；匿名清单全过 |
| 3 | 个别 overfull（<3 处）/ 表格样式小瑕疵 |
| 1 | 表格错乱 / 双栏溢出严重 / 匿名模式漏敏感信息 |

## 复现要求

- E6 幂等：同 paper.md + 同模板 → main.tex/refs.bib 逐字节一致（或仅注释时间戳差异）；
- format-report.md 含：模板来源三态、编译状态、红线 diff 结论、对账统计、降级记录。
